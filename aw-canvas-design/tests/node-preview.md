# 节点容器预览入口回归

规则事实源为 [逐卡入口](../references/workflow.md#节点容器打开预览入口)，浏览器通过条件见 [验收矩阵](../references/verification.md)。本用例不规定业务路由，只检查项目当前契约。

| 场景 | 预期 |
| --- | --- |
| 两张页面/Dialog/Sheet 卡片，含长标题与缩放 | 每张卡自身标题栏最右有打开预览入口，分别打开自己的当前场景；不依赖全局选中态 |
| 同一卡片 A→B→A variant | 每次真实单击在新标签打开对应场景；实际 screen/item URL 保留路由前缀、hash 及所需上下文，刷新仍恢复同一场景 |
| 鼠标点击、Tab + Enter | 一次打开，原页 URL、卡片位置和输入不变；不触发拖拽捕获、画布平移或场景重置；info、重置及正常拖拽仍各自工作 |
| 无 target、路由不可用、源码记录 | 不产生空链接、#、其他节点或整流程兜底；内容卡入口禁用并说明原因，源码证据仍可查看 |
| 判断/说明/引用语义节点 | 无真实预览时不出现伪造预览链接，既有引用跳转保留 |
| 整流程预览入口 | 独立保留，打开流程入口；不能替代逐卡按钮 |

## 本次维护验证范围

用临时 React 宿主直接导入 `reference/node-preview-button.tsx`，以 Playwright 真实点击验证 screen 场景 A→B→A、新标签内容与刷新、语言/主题/Fake 查询上下文、第二张缩放长标题卡的 item URL、Tab/Enter 打开、原页 URL/输入保留、标题指针捕获与重置计数为零、无 href 按钮禁用。该宿主不运行业务请求，不代表任一业务应用或真实画布库的完整验收；base path/hash、实际卡片拖拽和组件隔离由接入项目按矩阵验证。

HTML page-card 标准件及工作流 SVG 已渲染复核。参考 node 与 canvas-page TSX 通过 esbuild 编译（外部依赖保留为 external，此项不是项目类型检查）；已有三个 Node 测试文件共 14 项通过。验证结束关闭命名 Playwright 会话及临时 HTTP 服务。

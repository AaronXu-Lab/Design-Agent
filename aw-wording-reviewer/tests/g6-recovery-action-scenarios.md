# G6 出路验收回归

维护用情境。由 [工作流第 3 节](../references/workflow.md#3-执行相应检查) 进入 [G6](../references/rules.md#g6)，按每行给出的界面事实走查，比较审查结论与预期。以下是重命名弹窗的文档夹具。

| 提示出现时的状态与可用入口 | 预期结论 |
| --- | --- |
| 结果尚未确认。输入框下写「请点击『检查结果』」，实际复用输入框右侧的星光图标查询原请求。「检查结果」只出现在该图标的 Tooltip 和无障碍名称里。 | G6 不通过。指出输入框右侧入口无法按提示中的名称找到。可在提示旁提供可见且可执行的「检查结果」操作，配合「结果尚未确认」。 |
| 同一状态下，提示旁显示「检查结果」，当前支持的输入方式均能找到并触发该操作查询原请求。提示只写「结果尚未确认」。 | G6 通过。可见操作提供下一步，提示说明状态。 |
| 结果尚未确认。提示写「用输入框右侧的放大镜图标查询原请求」。该图标可辨认，在当前支持的输入方式下可找到并执行。Tooltip 补充用途，无障碍名称为「检查结果」。 | G6 通过。提示用位置与图标指明入口，Tooltip 和无障碍名称各自保留。 |
| 同一状态下可见「检查结果」，但此时按钮禁用。其他状态下按钮可用。 | G6 不通过。指出提示出现时操作不可执行，并按第 4 节处理控件问题。 |
| 同一状态下按钮可用，指针能执行，但页面支持的键盘操作无法聚焦或触发该按钮。 | G6 不通过。指出键盘操作受阻，修正后在原状态复验。 |
| 只提供「请点击『检查结果』」这段文字，缺少提示出现时的界面或交互证据。 | G6 待验证，继续独立文案审查项。 |

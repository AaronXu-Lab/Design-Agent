# 视觉方向探索

视觉方向未定或用户要求比较风格时读取。它服务已有自由探索分支；单纯讨论任务、结构或局部样式修正时，不展开完整视觉探索。完成条件与确认、交接规则以 [工作流](workflow.md) 为准。

## 将偏好转为有依据的选择

先明确品类、用户在代表页面看什么或做什么，以及允许变化的范围。按 [竞品研究](competitor-research.md) 查证有用的参考，实际看过画面才描述视觉；区分用户熟悉的任务组织、可调整的表现方式与参考中特有的品牌资产。说清沿用和改变的理由，不凭印象复刻竞品。

把「高级、克制、简洁」等词翻译成可观察的提案。例如，「克制」可以指强调色集中在主动作、减少装饰层级；「简洁」可以指降低同时展示的信息量，也可以指保留高密度内容但减少视觉分隔。结合本产品任务提出解释，证据不足时用小样帮助用户选择，不把这些词固定对应某种配色或大留白。

从产品内容、使用场景或已有品牌资产提取一句能指导取舍的体验意图，再推出布局、字体、色彩和用图的关系。隐喻须服务内容与操作，不能为了表现题材增加无用部件。

## 用简短方向卡指导小样

每个有实质差异的方向记录下列适用项，可用短段落或表格，不强填全部字段。初期只具体到足以作出当前选择，不提前制定完整视觉规格。

| 内容 | 要表达的决定 |
| --- | --- |
| 体验意图与依据 | 希望用户感受到什么；来自哪些任务、内容、品牌事实或明确偏好 |
| 固定与可变项 | 哪些结构、品牌、组件或 token 沿用，哪些可以探索 |
| 视觉关系 | 布局与阅读顺序、密度、字体层级、色彩用途、主视觉如何支持同一意图；已有约束锁定的项直接引用 |
| 保留与放弃 | 最值得保留的辨识点，以及主动舍弃的常见做法和理由；记忆点可以来自内容组织，不要求加动效或装饰 |
| 任务适配与代价 | 内容承载、可读性、操作成本、实现代价及尚未验证的部分 |

选择能暴露差异和任务负担的代表页面或状态，只制作当前判断所需的小样。后台可选列表与详情，复杂表单可选主要填写状态；首屏适合当前问题时才选首屏。沿用 [可视化对齐](visual-alignment.md) 的比较条件和实际查看要求，不为了展示风格复制多套完整产品。

## 检查是否真的不同

制作前比较方向卡和线框，制作后比较实际画面：

- 去掉方向名称和介绍，将小样缩小并排看，检查主次块面、阅读顺序与视觉重心是否仍能区分；再回到实际尺寸检查文字与细节。只换名称、装饰或主色的方案，应称为同一方向的变体。
- 在允许变化的维度里比较布局、字体、色彩和主视觉是否形成不同的整体关系。多个维度组合出差异比单独换色更有价值；品牌已锁定字体和色板时，可从布局、密度与内容组织探索，不强迫破坏约束来制造差异。
- 对照实际看过的参考，解释借鉴的关系和本产品的区别。新颖程度不是任务适配的替代，也不要求每轮加入极端方案或打破行业习惯。

候选过于相似时，重审当前问题和可变维度：确有必要再提出另一种关系；约束已指向一个合理方向时收敛，不为凑数量重做。用户反馈后保留有价值的辨识点，避免逐轮修成另一种未经选择的风格。

视觉小样只支持其展示范围内的判断。未覆盖的状态、响应式、动效与真实交互明确留待验证，不能据此宣称完整体验通过。不能查看画面时可交方向卡和源文件，但标明未验证实际视觉。

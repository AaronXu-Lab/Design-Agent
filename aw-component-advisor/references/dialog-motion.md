# Dialog / Sheet 动效专项

任务包含可交互 Dialog 或 Sheet 时读取。这是本 Skill 的验证要求，不冒充知识服务的组件规则；规范未覆盖时仍记未覆盖，动效观察单独记录。不在此固定 props、选择器、时长、缓动或动画技术，具体行为以当前证据为准。

## guidance：接入与验证计划

把进入与退出动画列为初版交付检查项，不留到视觉润色。从当前组件实现、样式入口和匹配 Example 核实动画由谁提供、如何启用，以及打开状态、Portal / presence 与退出后卸载的关系。库已内置动效时优先正确接入，避免重复叠加。

排查会截断动效的调用方写法：条件渲染、关闭时立即清空内容或移除容器、样式遗漏或被覆盖。检查**实例连续性**：表面实例在打开前已存在，打开状态在同一实例上切换；警惕按对象 key 重挂载、由路由或数据到达触发首次挂载、加载态与就绪态渲染在不同树位置。切换目标对象时只替换内容不替换实例，关闭后保留最后一项内容直到退出完成。当前源没有可用实现时说明缺口，在授权范围内补足调用方方案，不静默修改组件库。

验证计划包含：正常动效设置下首次打开、关闭、再次打开、打开另一个对象；有直接链接入口时单列其进入行为；本次实际支持的关闭路径；内容表面及遮罩；减少动态效果下的预期行为。只有静态稿时说明动态行为未验证。

## 检查：初版自检与 audit 共用

- **路径**：记录运行版本、入口与动态效果设置。从关闭状态首次打开观察进入；关闭时观察退出直至卸载；再次打开确认可重入；测试目标切换与适用的直接访问。覆盖本任务实际存在的关闭方式（按钮、取消、Esc、遮罩、提交成功、路由切换等），被业务禁止的路径不强行启用。共享同一关闭生命周期的路径可复用证据，但须确认各入口确实进入该生命周期。
- **事件证据**：用真实点击和按键触发，按路径记录过渡何时创建、实际时长、完成（finished）或取消，以及表面何时卸载。通过标准：进入和退出过渡都完成，且卸载发生在退出完成之后。录屏、时间线与不透明度/位移采样只作辅助；打开后截图、CSS 声明、非零 duration 或一次 `getAnimations()` 不能证明动效可见。
- **环境**：面板隐藏、窗口未聚焦可能导致渲染节流。先确认文档可见、时间线在推进；出现停在 starting/ending 或直接跳变时，先用事件证据复核，不直接归因于环境或判通过。减少动态效果设置单独核实其降级行为，不能用它代替正常动效结论；恢复检查中临时改变的设置。用户明确要求无动画时记录依据。
- **修复**：正常设置下观察到瞬现、瞬消或退出截断时，记录复现路径、预期来源和事件证据；只有与适用规则冲突才称规则违例。按现有授权定位接入、样式与生命周期并修复，只有审查授权时给最小修复建议。修复后重验进入、退出、重开、目标切换、直接访问及受影响关闭路径，并确认焦点恢复与背景交互限制未被破坏。

交付按进入、退出、再次打开、目标切换、直接访问、关闭路径与减少动态效果分别给出观察、证据位置、已修复与待验证项；未变更的有效证据可复用。

## 2026-11-12 合并验证

临时 Vite 宿主直接使用本包的 React 参考文件，在 StrictMode 下挂载 `CanvasPage`；依赖复用本机 React 19.2.8、ReactFlow 12.12.1、ELK 0.11.1、TypeScript 和项目已有设计系统，未修改业务工程或仓库依赖。

Playwright 真实点击验证：

- 初始零 iframe，依次激活四个场景始终最多三个，回收最早实例。
- 输入错误值并产生校验提示，回收重开后字段和错误完整恢复。
- 逐卡新标签打开对应 screen，保留实际路由前缀、语言、主题与 Fake 上下文，刷新有效且原卡片输入不变。
- 标题栏更多操作中的重置清快照并卸载，再激活回默认值。
- 切换注册流程再返回主流程，外层会话保留原输入。
- 独立尺寸夹具同时传 `state/restore` 与 `ready/measure`：保持 640×800 渲染视口与独立裁切原点，展示高度可双向变化；异步 loading 保留已提交几何，ready 后更新；回收后输入和几何仍正确恢复。
- 独立 flow/screen/item 的正常、错误、取消、重置和刷新均可操作；源码记录与未知目标不挂载表单，观察范围内无网络写入和浏览器持久存储。
- StrictMode 重复挂载不会留下重复 ready 导致的恢复超时；失败提示不覆盖激活入口。

TypeScript strict 检查及生产构建通过，构建实际生成 ELK Worker。浏览器夹具只证明本参考实现的消息、状态与尺寸协作；不证明任意业务组件、hash 路由或生产副作用隔离已通过，也没有新增性能基准结论。

三张变更的工作流 SVG 已渲染复核，主分支、文字和连线可辨；未变更的组件动效、目录、视口控件、逐卡链接及尺寸基础契约与远端逐文件核对保留。

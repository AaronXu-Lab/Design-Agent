# 实际组件预览与场景设计

实现或调整节点或平铺条目内容时读取。环境层的隔离和拖拽机制见初始化模块，此处定义预览与场景质量；AaronUI-Web Dialog 的语义、组合、内容和组件布局约束由 `aw-component-advisor` 从本地 MCP 读取，不在此建立第二份规范。节点卡片的外壳（顶栏、预览区、底栏的场景切换；出口和入口小旗仅流程模式适用）以 [canvas-kit](../assets/canvas-kit/) 为视觉与交互标准，规则见 [画布呈现规范](canvas-presentation.md)；项目有设计系统时用其组件与 token 实现同等效果。卡片预览里不显示全局演示或调试入口。

## 复用与演示边界

执行[共享展示契约](workflow.md#从初始化建立同一套展示代码)：节点和实际页面直接引用同一展示组件与样式，通过 props、适配器或依赖注入切换真实数据与隔离场景。新增布局、字段、文案及视觉状态写在共享展示层，不能在预览适配器中重写同一表单或用预览专属 CSS 覆盖来掩盖差异。实际入口的请求与导航留在业务控制器；无实际对应的新设计使用唯一展示实现并记录待接入，不提前接通业务副作用。

真实交互预览的输入、选择、按钮禁用/校验、菜单、帮助链接、关闭和重新打开均要可操作。演示结果由确定的场景输入驱动，重开是否清空/保留由业务语义决定；用明确重置恢复初始场景，不能让前次预览污染其他节点。

遵守项目 Fake/演示开关与共享数据约定；适用且可用时使用 aw-design-fake。对认证 SDK、网络 client、表单 action、导航和回调逐项确认隔离，阻断真实授权、凭证提交、账号修改及业务写入。使用合成数据，不从现有会话读取秘密充当 fixture。检查演示关闭状态。文档链接可保留真实安全地址；授权按钮不能因名字像链接就放行真实授权。

## 每个场景单独设计

- 字段含义、标签、必填标识、帮助说明、默认值、校验时机和报错位置依据当前场景，不统一套同一表单。
- URL 用合适输入与格式校验，密码用隐藏输入及项目允许的显隐控件，多行内容用文本域，枚举用选择组件；不要把 token、URL、JSON、说明文本全部当作普通单行字符串。
- 核对文档链接目标、外链反馈、主次按钮、危险/取消操作、加载与不可用原因及最终结果说明。中文文案适用且可用时使用 aw-wording-reviewer，沿用当前修改授权。
- 弹层尺寸与滚动归属按真实组件实现和适用规范验证，不为整理画布固定高度裁掉内容。检查容器最小尺寸、长文本、选择菜单、校验信息和窄视口；预览适配不能改变业务组件的滚动与操作能力。Dialog 约束通过当前源规范核对，未覆盖的组件记录实际行为证据，不能把本节预览检查当作独立组件规范通过。

## 预览视口与稳定尺寸

两种模式使用 iframe 或独立视口时均适用。本节是尺寸与动态高度的单一规则源；外壳、kit 和验收矩阵按需引用，不另设尺寸策略。

- **四种几何分开记录**：原组件内容边界（含标题、内容和操作区）；决定百分比、`vw/vh`、断点和 `max-height` 的响应式渲染视口；卡片承载的外部展示边界（含必要留白及展示原点）；最后作用于展示区域的缩略比例。画布缩放另记，不能把小内容矩形直接作为下次 iframe 视口。
- **动态卡片高度**：展示边界必须随当前真实内容增高或缩短，重新计算卡片和行/节点布局；不能为平铺对齐固定/压缩卡片、裁掉字段、校验信息或操作区。对齐使用顶端基准、间距和实测槽位。持续测量异步内容、列表增删/空态、错误出现与消失、步骤推进/返回、场景切换及重置；只有第一次测量或只允许增高均不通过。
- **先建立自然渲染环境**：检查声明宽度、min-width、固定/百分比尺寸、`calc`、断点留白、Sheet 锚定和过渡，给出不压缩原组件的安全视口。槽位不足时扩大并允许横向平移，外部统一缩放。可将稳定渲染视口与动态展示区域分离：在自然视口测量完整组件及留白，再用外部容器和偏移展示该区域；展示原点与宽高均按未缩放坐标记录，偏移和占位使用同一缩略比例。具体视口由业务约束验证，不把某案例的 720×1000 固化成通用值。弹出菜单等临时浮层仍须可见、可达，不能因外部区域截取丢失。
- **避免反馈收缩**：无视口依赖的测量壳才可把根尺寸直接回写 iframe；响应式弹层使用上述分离方案、受控测量壳、声明尺寸或经验证的回算/限界方案。例如内容宽度为视口的 90% 时须按同一规则回算，不能每次加固定留白后反复缩小。禁止“先缩视口 → 组件被挤压 → 再测到更小”。不收敛时保留最后安全视口、报告缺口，不能用最小尺寸或内部样式覆盖掩盖裁切。
- **消息与就绪分离**：接收端验证同源 `origin`、所属 iframe 的 `source` 和当前实例；尺寸为有限正数，展示原点为有限非负数，展示边界不超出声明渲染视口。校验完整消息后再应用，旧实例消息不得更新当前卡片。临时尺寸不提交到可见几何，也不代表内容就绪或提前撤骨架；发送方在当前目标内容可见、可操作且布局就绪后明确报告就绪。旧协议只限已证明首报即就绪的同步测量壳，异步场景须适配。就绪也不等于稳定验收通过。
- **保留最后提交值**：场景切换、重置与预览重新加载开始时只将当前代次标为 loading，保留上一版已提交的展示宽高、裁切原点及渲染视口；首次加载没有提交值时使用安全初始尺寸。`loading` / `ready:false` 的测量可留作诊断，不得改卡片占位、iframe 渲染/裁切尺寸或触发布局；不能先应用临时几何再补判断。目标场景的内容与布局就绪、消息合法且属于当前实例/代次后，原子提交完整几何并撤骨架；之后继续接受就绪内容的真实增高与缩小，不能使用永久固定高度或历史最大值掩盖跳变。稳定验收仍按下条单独执行。
- **切换生命周期与多消费者**：已提交几何由稳定卡片身份持有；重挂载 iframe 时不能连同持有几何的外层一起按场景 key 重置。开始切换即失效旧代次，异步发送方在替换内容前清除 readiness，禁止默认加载页、旧场景或未完成布局沿用 `ready:true`。跨重载/同一 iframe 的迟到消息按请求代次隔离（例如双方回传宿主生成的 token）；仅检查 `source` 不足以区分复用的 WindowProxy。参考桥接不内建代次握手，宿主须在有此类竞态时补齐。所有尺寸消费者（预览外框、节点数据/缓存、iframe 裁切与行/连线布局）须共享同一 readiness 和代次判断，不能只保护其中一条路径。加载失败或超时保留最后提交几何（初载保留初始值），显示失败/重试状态，不把错误页或超时当作就绪；重试成功后恢复真实尺寸提交。业务组件已就绪后正常呈现的校验错误仍按真实内容测量。
- **有界稳定检查**：等待字体、异步内容与进入动画，对渲染视口、内容矩形、展示原点及边界连续采样；可从 3 次、间隔 150ms、容差 1px 起调，窗口覆盖已知过渡。上述每次动态变化后重开稳定窗口，继续观察后续变化；超时、不停缩小或振荡记失败，不无限阻塞其他条目。
- **保留原组件滚动**：长内容沿用真实组件原有 `max-height` 和内部滚动，不强迫全部内容无界展开，也不覆盖组件库内部样式来凑卡片高度。稳定后验证标题、字段/校验和底部操作可见或按原滚动机制可达、可操作，Sheet 与菜单未裁切；重复进入/重置仍成立。证据分别记录四种几何、变化前后尺寸和连续样本，瞬时矩形或单张截图不足以通过。

## 多步骤与授权能力（仅相应业务读取此节）

多 Step Circle 可承载授权、连接或其他分步任务；步骤数量、名称、解释、等待态、完成依据和退出语义由每个业务对象实际能力决定。将能力证据映射到场景配置，不用一个泛化 OAuth 模板覆盖所有对象，也不把点击下一步视为真实服务完成。

二维码只在确有支持依据的分支出现；源案例把二维码放在 Circle 上方，这是条件成立时的布局参考，不是所有 OAuth 的功能承诺。预览二维码使用无授权作用的演示内容。未知能力标为待核实，不默认为支持；不支持时使用其实际授权路径。

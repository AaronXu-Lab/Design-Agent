# 衣集设置：信息冗余审计案例

日期：2026-11-09。使用 Skill：`aw-ux-info-redundancy-audit` 1.8.0。目标：在隔离夹具中检查衣集设置，并实施简化。记录用于后续迭代，暂不调整 Skill 规则。

## 观察和改动

| 原界面 | 改动 | 依据 |
| --- | --- | --- |
| 连接选项、模型、Prompt 和日志由多层卡片承载；移动端需要滚动才能扫完设置入口。 | 单一面板内平铺六项，用分割线分隔；四个展开入口整行可点击。 | 卡片边界没有增加任务含义，分组和可操作性由行标题与展开状态承担。 |
| 「API Key 模式」下的「BYOK」单独出现，且连接方式与透明图开关同卡。 | 改为「OpenAI 连接方式」和「自带密钥（BYOK）」；「生成透明图」独立成行。 | 前者决定请求如何发送，后者决定处理结果，是两个独立决定。保留配额、照片传输、密钥存放与移除、测试连接以及关闭透明图的后果。 |
| 「恢复默认 Prompt」在两个输入框之前。 | 移到两项之后。 | 操作同时影响两个字段，先展示它的作用范围。保留标签输出约束。 |
| 日志开关和导出常驻，构建号单独占一行。 | 合并到「故障排查」，展开后可记录、导出和查看构建号。 | 三项服务排查任务。关闭日志会清空记录的提示仍贴着开关，导出入口保持可访问。 |
| 「数据与隐私」含本地未加密、清站点数据会丢相册及定期导出提示。 | 保留原有独立入口和说明。 | 相册保存与恢复不同于 API 传输，也不同于诊断日志。 |

改动位置：Aaron-Portfolio 的 `src/lib/wardrobe/app.tsx`、`src/lib/wardrobe/style.css`。前后截图位于该仓库的 `output/playwright/wardrobe-settings-before.png`、`output/playwright/wardrobe-settings-after.png`。

## 证据与边界

- 在独立浏览器会话中使用模拟模型响应和合成日志。对照 390 px 视口，另测 320 px 下自带密钥、展开模型时没有横向溢出。
- 实测空密钥不能测试连接、模拟失败后重试成功、关闭透明图只禁用透明图模型、Prompt 可重置、隐私说明可展开、日志能下载且关闭后清空、Escape 关闭并将焦点返回入口。构建通过，衣集 16 项测试通过。
- 检查了对话框和开关的可访问名称与键盘焦点。未实测屏幕阅读器、真实 API 或真实相册；本地 AaronUI-Web 知识服务未连接，组件规范待核对。

## 供迭代考虑

- 区分三种减负手段：去掉不提供分组价值的边界、把同一任务的内容移到一起、删除已被完整表达的事实。此例主要使用前两种，不需要凑文案删除项。
- 条件信息先判断它服务哪个决定，再决定默认可见还是按需展开。低频排查可以折叠，但开关后果、失败反馈与恢复动作应在对应状态就近可见。
- 可把此例用作状态验证样本：同一窄屏对照前后，并覆盖默认、自带密钥、失败重试及开关依赖。将实现证据、可访问性实测和组件规范覆盖分开记录。

## 人工复看后的修正

默认连接说明改为「100 请求/IP/天」。用户已在衣集内，且「OpenAI 连接方式」已经提供了理解该选项所需的语境，因此删去前半句；配额仍保留次数、IP 和天三个要素。这条判断已纳入 Skill 1.8.1。

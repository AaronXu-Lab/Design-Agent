# flow 目录回归

此案例来自用户明确确认的画布设计约定，用于说明和回归，不是 PRD、组件库规范或固定业务模板。语义事实源见 [建模](../references/modeling.md#流程目录归属仅-flow)，图标与交互见 [呈现](../references/canvas-presentation.md#flow-目录)。

| Section | 根任务 | 文件夹内入口（按类型） |
| --- | --- | --- |
| 主流程 | 直接连接 | 无从属流程，直接可点击 |
| 主流程 | 云端凭证 | 云端凭证（主）；外部账号授权、填写凭证（子）；多项凭证（分支） |
| 主流程 | 本地授权 | 本地授权（主）；设备与云端凭证（分支） |
| 其他流程 | 功能材料补充 | 独立补充任务 |
| 其他流程 | 异常修复 | 跨流程恢复任务 |

组合流程的凭证步骤引用已有云端凭证流程，不再复制整套画布。`flow-directory.test.mjs` 验证结构、类型和 ID/预览/引用不变；另用批量导入案例验证业务名及根任务数量不是实现常量。

宿主或参考侧栏浏览器回归：

1. 默认目录显示两个任务 Section；有从属项才建文件夹。展开云端凭证，文件夹只用 Folder/FolderOpen，首项主入口用 Path，授权/表单子流程用 ArrowSquareOut，多项凭证分支用 GitBranch；全部缩进项仍有图标，尺寸/线重一致。
2. 点击主入口及各从属入口，核对当前高亮唯一、原 URL/ID 与 `?preview` 不变。折叠/展开不能导航或丢失当前项。直达/刷新从属流程及从其他 Section 切回时显示所属文件夹与当前高亮。
3. 分别打开独立预览再返回，保留原流程与宿主 query/context 约定；从组合中的引用跳转到已有云端凭证并验证既有返回路径。未知 ID 沿用明确空态。
4. 把从属表单临时错放到其他组应被归属检查发现；状态和授权阶段不能只因名称不同就成为根任务。空目录、只有一个根任务与无从属项均可用。
5. 切换到 tiles 比较 Dialog/Sheet：仍为独立类型 Section Group，下接业务模块平铺，无文件夹/折叠树；不得应用此 flow 分类。

纯目录维护只回归受影响的导航/呈现；此清单不要求重验未变的业务组件、连线或尺寸协议。静态 HTML 没有实际业务 URL/预览/引用导航，不能以其演示点击声称宿主路由已验证。
